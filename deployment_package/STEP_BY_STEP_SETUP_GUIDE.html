🌐 2. FTP Connection Guide (FileZilla)

  1. Download and open FileZilla Client (free from filezilla-project.org).
  2. Go to File > Site Manager > New Site.
  3. Configure the connection settings:
    • Host: ftp.yourdomain.com (or server IP address)
    • Port: 21 (or 22 if using SFTP)
    • Protocol: FTP - File Transfer Protocol
    • Encryption: Require explicit FTP over TLS (or Only use plain FTP if TLS not supported)
    • Logon Type: Normal
    • User & Password: Your cPanel / hosting FTP credentials
  4. Click Connect to establish the connection.

🚀 3. Uploading Files to Your Web Server

Method A: cPanel File Manager (Recommended - Fastest)

  1. Log into your hosting cPanel.
  2. Open File Manager and navigate to public_html (or your subdomain directory).
  3. Click Upload and upload omc_mlm_ftp_dist.zip.
  4. Right-click the uploaded zip file and select Extract.
  5. Confirm all files (index.html, assets/, .htaccess) are directly inside public_html.

Method B: FileZilla FTP Upload

  1. Unzip omc_mlm_ftp_dist.zip on your local computer.
  2. In FileZilla right panel, open /public_html.
  3. In FileZilla left panel, select all extracted files and folders.
  4. Right-click and select Upload.
  5. Verify .htaccess is uploaded (In FileZilla menu: Server > Force showing hidden files).

🗄️ 4. MySQL Database Setup via phpMyAdmin

  1. In cPanel, click MySQL Databases (or MySQL Database Wizard).
  2. Create a new database (e.g., user_omcmlm).
  3. Create a MySQL user, generate a secure password, and add the user to the database with ALL PRIVILEGES.
  4. Go back to cPanel home and open phpMyAdmin.
  5. Select your database from the left navigation panel.
  6. Click the Import tab at the top.
  7. Click Choose File and select omc_mlm_database.sql.
  8. Click Go / Import at the bottom.
  9. All 9 tables with complete seed data, supported Thai & Lao banks, and test members will be created!

⚙️ 5. Apache .htaccess & Preventing 404 Errors

Because the app is a Single Page Application (SPA), routing is handled on the client. The included .htaccess file redirects all paths back to index.html so refreshing pages like /dashboard or /genealogy works seamlessly:

<IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>
